# Web pública — Asociación Videal

Sitio estático con [Eleventy](https://www.11ty.dev/). Por la salud mental — acompañamiento y cuidado.

## Desarrollo

```bash
npm install
npm run serve   # http://localhost:8080
npm run build   # genera _site/
npm test        # test de integridad del build
```

No contiene datos personales sensibles ni backend. El contacto se centraliza en el número y email de la asociación.
